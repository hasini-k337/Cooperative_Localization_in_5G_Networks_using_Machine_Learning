GRAPH 1: POSITIONING ERROR COMPARISON
================================================================================
File: 1_positioning_error_comparison.png

PURPOSE:
This graph compares the mean positioning error (in meters) across different machine 
learning models on four datasets: UJIIndoorLoc (UJI) and three SODIndoorLoc 
sub-datasets (SOD1, SOD2, SOD3).

KEY INSIGHTS:
1. **FasterKAN Superiority**: Our improved FasterKAN consistently achieves the 
   lowest positioning errors across all datasets, demonstrating its effectiveness.

2. **Dataset Difficulty Gradient**: 
   - UJI dataset shows the highest errors (most challenging)
   - SOD datasets show progressively lower errors (easier tasks)
   - This reflects the complexity differences between datasets

3. **Model Performance Ranking**:
   - FasterKAN (Improved): Best performance across all datasets
   - KNN: Surprisingly good performance, especially on SOD datasets
   - CNN: Moderate performance, better than traditional ML methods
   - Traditional ML (PLSR, SVR, RFR): Generally higher errors

4. **Why FasterKAN Performs Better**:
   - Learnable activation functions adapt better to WiFi signal patterns
   - RSWAF (Reflectional Switch Activation Function) captures non-linear relationships
   - Better handling of sparse WiFi fingerprint data
   - Optimized architecture for indoor localization tasks

WHY THIS MATTERS:
Lower positioning errors directly translate to more accurate indoor navigation, 
which is crucial for real-world applications like shopping malls, hospitals, and 
airports where precise location information is essential.

GRAPH 6: CPU INFERENCE TIME COMPARISON
================================================================================
File: 6_cpu_inference_time.png

PURPOSE:
This graph compares the inference time (in microseconds) for different models 
when running on CPU only.

KEY FINDINGS:

1. **Performance Spectrum**:
   - Fastest: PLSR (3.04μs), PLSDA (9.09μs), RFR (12.43μs)
   - Moderate: RFC (83.82μs), KNN (380-806μs)
   - Slower: CNN (353-399μs), FasterKAN (130-183μs)
   - Slowest: SVR (15,930μs), SVC (8,112μs)

2. **FasterKAN vs CNN on CPU**:
   - FasterKAN: 130-183μs (regressor vs classifier)
   - CNN: 353-399μs (regressor vs classifier)
   - **FasterKAN is ~2.7x faster than CNN on CPU**

3. **Why Traditional ML is Fastest**:
   - Simple mathematical operations
   - No complex neural network computations
   - Optimized implementations in scikit-learn
   - Direct matrix operations

4. **Why SVR/SVC are Slowest**:
   - Support Vector Machines require complex optimization
   - Kernel computations are computationally expensive
   - Not optimized for real-time inference

PRACTICAL IMPLICATIONS:
- FasterKAN provides a good balance between accuracy and speed
- Suitable for real-time applications where both accuracy and speed matter
- CPU-only deployment is feasible for resource-constrained environments
